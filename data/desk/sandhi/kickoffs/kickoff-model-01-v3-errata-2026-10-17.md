# Errata to Kickoff Model 01, version 3 (October 17, 2026), for run 3.1

Prepared with Mantri (main) after run 3 reported that the version 2 kickoff, which version 3 inherits definitions from, was absent from the v3 bundle. Run 3's output stands as a record; it is not read by run 3.1. This file is read with `kickoff-model-01-v3-gated-states-2026-10-17.md` and takes precedence where the two differ.

1. **The inherited definitions are in the bundle.** `kickoff-model-01-v2-gated-states-2026-10-17.md` is included. Version 3's "version 2's definitions stand except where this section changes them" now has its referent: the line observation, the per-record threshold T_k, the alternation exclusion (2.2 of v2), the straddling repeat (2.3 of v2), channels W and F with 4 kHz censoring and the record's-own-floor count beside, the kind events, the copies check split by span, the stamp channel S, the classes, the dependence tests and the model's own check are as version 2 states them, changed only where version 3 says so. The frequency ledgers for tests 7 to 10 must reproduce the counts the runner prompt lists (within 0 of 509, 349, 9,100, 9,033, 7,073 at 4 kHz; boundaries 0 of 77, 0 of 55, 1 of 125, 0 of 124, 0 of 98); a difference is a difference in reading the records and is reported, not reconciled.

2. **The stamp channel's 143 crossing (v3 section 2.5), corrected.** Channel S is defined on the S fit's detuning (`S.params.Delta_MHz`, as version 2 states). Between test 7 and test 11's job 1 the S fit's detuning moved by about 153 kHz; the P model's frame (Δ0) moved by about 63 kHz. Version 3's sentence attached the 63 kHz figure to the S fit; that was wrong. The crossing is one event on the S detuning either way; report both numbers with their fields.

3. **Channel B is fitted by design class, never pooled for prediction.** At the record's own resolution the monitor's span means carry errors of about 0.002, so five combined errors is about 0.016 in weight, while a shuffled job's span means carry about 0.003 to 0.005. Fit p_B separately for shuffled boundaries and for monitor boundaries; report the pooled number beside with the Fisher test between the classes; every prediction for a shuffled job uses the shuffled p_B and every prediction for a monitor uses the monitor p_B. The fixed 0.10 count stays beside both.

4. **A wording correction in the records the bundle quotes, not a change of definition:** the 0.063 step of test 11 job 1's span means (0.496 to 0.433) is about 13 combined standard errors under the stated calculation, not twenty as Mantri's test 11 read said.

5. **Unchanged:** everything else in version 3, including the retirement of the "count fewer events" tie-break, the within-span weight channel, the between-jobs weight trial (same estimator only), the split observable, the estimator table, and section 7's predictions, which are now written from the class-specific p_B.
